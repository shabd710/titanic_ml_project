
# Titanic Survival Prediction 🚢

This is my **first machine learning project**!  
The goal: predict whether a passenger survived the Titanic disaster using Python and basic ML techniques. 🐍💻

---

## 🛠️ What This Project Does

- Loads and explores the Titanic dataset 📊  
- Handles missing values (like `Age`) 🧹  
- Converts categorical data (like `Sex`) to numeric 🔢  
- Splits data into training and testing sets ✂️  
- Scales features using `StandardScaler` ⚖️  
- Trains a **Logistic Regression** model 🏋️‍♂️  
- Predicts survival and evaluates the model using:
  - **Accuracy** ✅  
  - **Classification Report** 📝  
  - **Confusion Matrix** 📈  

---

## 📂 Dataset

- Source: [The dataset file is included in this repository: `titanic_data.csv`] 
- Columns used: `Survived`, `Pclass`, `Sex`, `Age`, `Fare`, `SibSp`, `Parch`
